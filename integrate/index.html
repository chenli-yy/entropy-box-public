Query the artifact from your agent

A read-only retrieval endpoint over the evidence corpus is open. No registration, no API key, no client software to install. Three ways in, in increasing order of setup cost — most agents need only the first.

Scope, stated up front. The open endpoint serves concept-level evidence retrieval: vector plus keyword search over the research corpus, suited to questions about a specific algorithm, library or framework. Complex task decomposition, cross-topic chain assembly and node-level graph queries are implemented and usable through the web interface, but are not yet exposed as an API. See the capability table at the bottom.

Plain HTTPrecommended

Tell your agent about this endpoint and it will construct the request itself. Nothing to install.

POST <api-base>/api/evidence/search
Content-Type: application/json

{
  "query":  "<a concept, algorithm, library or framework name>",
  "topic":  null,
  "top_k":  10,
  "mode":   "hybrid",
  "rerank": true
}

Verify from a shell:

curl -X POST "$ENTROPY_BOX_API/api/evidence/search" \
  -H "Content-Type: application/json" \
  -d '{"query": "Reeds-Shepp curve shortcut expansion", "top_k": 5,
       "mode": "hybrid", "rerank": true}'

Responses are de-identified — no internal paths or surrogate identifiers — so they can be quoted to an end user directly.

Agent Skill declaration

For any agent runtime that consumes a skill or custom-tool manifest. Same endpoint, wrapped in a declaration.

name: embody-ai-knowledge-base
description: >-
  Query the Entropy Box embodied-AI research corpus — topic graph, engineering
  paradigms, open-source assets, algorithm selection. Suited to concept-level
  questions about a named algorithm, library or framework (e.g. "yolov6",
  "Reeds-Shepp", "MoveIt servo"). Not suited to multi-topic comparative
  reasoning.
endpoint: POST <api-base>/api/evidence/search
payload:
  query:  "<algorithm / library / concept name, or a simple question>"
  top_k:  10
  mode:   "hybrid"
  rerank: true

MCP stdio server

If your client speaks MCP over stdio rather than raw HTTP, this small server wraps the same endpoint.

pip install mcp
curl -o evidence_search_server.py <api-base>/mcp/evidence_search_server.py

Then register it, replacing the path with wherever you saved the file:

{
  "mcpServers": {
    "entropy-box-search": {
      "command": "python",
      "args": ["/absolute/path/to/evidence_search_server.py"],
      "env": { "EVIDENCE_API_BASE": "<api-base>" }
    }
  }
}

Offline alternative

If you would rather not depend on a live service, the published data files cover a good deal on their own: bilingual capability and asset indices, the three-level taxonomy, the 126-query retrieval golden set, the adjudicated duplicate ledger, and nine topics reproduced in full with their task-chain diagrams. All under CC BY 4.0.
